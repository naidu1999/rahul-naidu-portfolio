# Rahul Naidu — Portfolio

A standalone, responsive portfolio for Rahul Naidu, built with HTML, CSS and vanilla JavaScript. The hero visual uses a small canvas-based 3D projection; no framework or build step is required.

## Open locally

Open index.html in a browser. The site is also ready to deploy as a static website from this folder.

## Content source

The public GitHub profile and repository READMEs are the source for project descriptions, repository links, and AI/ML focus areas. The Projects section includes all 13 public project repositories, with filters for AI, machine learning, data analytics, computer vision, and MLOps; GitHub AI projects are identified as postgraduate study work. The profile-only README repository is not listed as a project. The Wipro role and accomplishments were supplied by Rahul, and the resume provides the remaining work and education history in assets/.
